# Events

Every event the departments sent, merged: when several departments sent the same event, it is one entry here, with every version they wrote kept in its folder. Where versions differ, Marketing's is used, because Marketing organises and publishes every event once it has happened (Vasco's rule); four events have Marketing's published LinkedIn recap, in the event's `posts/` folder. One folder per event, with a README (text for the site, details, what to check, every version received), its photos, videos and recap.

Photos and videos are exactly the files received. Where the same photo arrived twice, the higher-resolution copy is kept. One photo is an iPhone .heic original with a full-size .jpg copy next to it.

`events.json` has them all in the site's event format.
